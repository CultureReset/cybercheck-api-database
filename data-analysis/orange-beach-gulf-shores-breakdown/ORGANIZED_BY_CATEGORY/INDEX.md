## CSV Format

Each CSV file contains:
- **name** — Business name
- **address** — Full address
- **website** — Website URL (if available)
- **phone** — Phone number (varies by source)
- **rating** — Business rating (varies by source)
- **facebook** — Facebook URL (Google Sheets only)
- **instagram** — Instagram URL (Google Sheets only)

## Usage Tips

1. **Open in Excel/Sheets** — Import any CSV to filter, sort, analyze
2. **Find by category** — Each file is organized by business type
3. **No franchises** — All chain businesses already removed
4. **Contact info** — Most include phone numbers and websites
5. **Compare sources** — Same category across different sources for completeness
